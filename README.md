# ZaloRelay

Telegram-managed bridge that forwards approved Zalo admin commands (text or CTA with buttons) as immediate messages to specified Zalo groups/pages, with delivery logs and retry.

Spec: [`docs/blueprint.md`](docs/blueprint.md).

Built on [agnt-gm.ai](https://agnt-gm.ai). The whole bot is built and refined here as pull requests across successive build passes.
